# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The Axil development team takes security seriously. If you discover a security vulnerability in the Axil language compiler, generated binary templates, or web developer studio, please do **NOT** open a public issue.

Instead, please report security vulnerabilities privately:
- **Email**: Send detailed steps to reproduce to **kshatriya205902@gmail.com**
- **GitHub Security Advisory**: Open a private advisory at [https://github.com/irealashu/Axil/security/advisories](https://github.com/irealashu/Axil/security/advisories)

Please include:
- A clear description of the vulnerability.
- Proof-of-concept `.axil` source code or reproduction steps.
- The operating system, Python version, or browser used.
- Any potential remediation suggestions.

You should receive an acknowledgement within 48 hours, followed by updates on triage, patches, and release coordination.
